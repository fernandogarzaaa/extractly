API docs

Plain HTTPS, JSON everywhere, Bearer auth. Base URL is this server.

Authentication

Create a key on the dashboard, then send it as:

Authorization: Bearer ex_live_...

Endpoints

POST /v1/keys: create a free API key

curl -X POST {{ request.base_url }}v1/keys \
  -H 'Content-Type: application/json' \
  -d '{"label":"my zapier flow"}'

# 200
{"key":"ex_live_...","key_id":7,"tier":"free",
 "quota_daily":25,"note":"This key is shown once. Store it securely."}

Rate limited per IP ({{ cfg.key_create_per_hour }}/hour). The raw key is shown once and only its hash is stored.

POST /v1/extract: run an extraction

curl -X POST {{ request.base_url }}v1/extract \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer ex_live_...' \
  -d '{"text":"Invoice from Acme Corp dated 2026-09-15 for $1,250.00",
       "schema":{"type":"object",
                 "required":["vendor","date","total"],
                 "properties":{"vendor":{"type":"string"},
                               "date":{"type":"string"},
                               "total":{"type":"number"}}}}'

# 200
{"data":{"vendor":"Acme Corp","date":"2026-09-15","total":1250},
 "confidence":1.0,
 "model":"{{ cfg.model }}",
 "usage":{"prompt_tokens":312,"completion_tokens":148},
 "quota":{"used_today":3,"quota_daily":25},
 "request_id":"req_1791015000000"}

Limits: text up to {{ cfg.max_text_chars }} chars, {{ cfg.extract_per_minute }} calls/minute/key, daily quota by tier. If the model cannot produce schema-valid JSON after a retry, you get 422 extraction_failed, never fabricated data.

GET /v1/usage: quota and consumption

curl {{ request.base_url }}v1/usage \
  -H 'Authorization: Bearer ex_live_...'

# 200
{"tier":"free","used_today":3,"quota_daily":25,
 "resets_at":"2026-10-03T23:59:59Z"}

POST /v1/upgrade: redeem a Gumroad Pro license

curl -X POST {{ request.base_url }}v1/upgrade \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer ex_live_...' \
  -d '{"license_key":"YOUR-GUMROAD-LICENSE"}'

# 200
{"tier":"pro","quota_daily":2000}

The license is verified live against Gumroad. Unknown licenses get 402 invalid_license.
